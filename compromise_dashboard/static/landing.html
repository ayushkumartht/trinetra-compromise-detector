The problem

Attackers changed.
Signatures didn't.

Indicators of Compromise (hashes, IPs, domains) only describe attacks someone has already analysed. Modern intrusions arrive before any IoC exists.

IoCs arrive weeks late

An indicator is published only after an incident has been analysed. Until then, signature tools see nothing.

Living off the land

Attackers use built-in tools and stolen credentials. There is no malicious file to match at all.

Edge devices are blind spots

Routers, firewalls and VPNs can't run endpoint agents, yet they are today's favourite target.

How it works

From raw telemetry to a
verdict you can defend.

One engine for every device class. Every number is calibrated, every verdict is explained.

  1. 01

    Collect

    Slips/Zeek flows and DNS, router & firewall syslog and configs, host logins and processes.

  2. 02

    Normalise

    Everything becomes one event language (UBT), so one engine covers four device classes.

  3. 03

    Learn normal

    28 behaviours per device every 15 minutes, compared with its own past and its peers.

  4. 04

    Detect & fuse

    8 detectors → calibrated p-values → Cauchy fusion → CUSUM persistence.

  5. 05

    Verdict

    Compromised only with ≥ 2 independent ATT&CK stages. Forensic report included.

TRINETRA features

Eight independent detectors

Eight ways of noticing
that something is off.

Each detector sees one facet of a compromise. Alone, each has blind spots; fused, they catch all seven attacked devices in the benchmark.

Minimising false alarms

Eight layers between
noise and a verdict.

  1. Own baseline + time of dayA 2 a.m. backup is normal for that server.
  2. Calibrated p-valuesThresholds mean a known false-alarm probability.
  3. Cauchy fusionOne noisy detector cannot convict alone.
  4. CUSUM persistenceBlips fade; low-and-slow attacks accumulate.
  5. Fleet consensusChange on many peers at once is IT, not intrusion.
  6. Change-window contextKnown admin + maintenance window = planned.
  7. Kill-chain corroboration"Compromised" needs ≥ 2 attack stages.
  8. Gated learning + feedbackNo baseline poisoning; analysts can mark benign.

Get started

Up and running
in one command.

No GPU, no cloud, no internet connection. A week of 22 devices is analysed in about 30 seconds on a laptop CPU.

  • Agentless for routers & firewalls (syslog, configs)
  • Native Slips module for live network traffic
  • CEF export to Splunk, Elastic, QRadar, Wazuh
# Windows · Linux · macOS
cd slips
pip install -r compromise_dashboard/requirements.txt
python -m compromise_dashboard
# → http://127.0.0.1:5050
# Ubuntu · Debian · Red Hat · Fedora · Kali (or Docker)
./slips.py -i eth0            # live capture
python -m compromise_dashboard \
    --slips-output output/<run>
